## 使用asyncio协程异步读写
客户端可以同步写，但服务器需要处理并发连接和重叠请求，必须异步读写。
协程本质在同一线程中阻塞，事件await()让出控制权，通过信号唤醒协程
当只有同一协程，相当于阻塞
## 为什么不使用线程？
1. 任务性质：
这个 daemon 的工作负载是什么
绝大部分时间在等——等 LLM API 返回、等客户端发下一条命令、等用户 permission 响应。几乎没有 CPU 密集计算。
2. 资源浪费：
每个线程需要分配栈内存，线程切换需要上下文切换，这些操作都是成本高昂的。
3. Python 的 GIL：
Python 是单线程的，多线程得不到并行
